# 변인 카탈로그 v1 (초안)

세 겹 구조(칸의 값, 칸의 물질, 유닛의 값) 위에 전장 전체 값을 하나 더 얹었습니다. 모든 항목은 제안이며, 데이터로 정의되어 나중에 계속 추가할 수 있게 설계합니다.

## 0. 변인 하나가 갖는 정의 (모든 변인 공통 틀)
- 범위: 최소/최대, 기본값
- 퍼짐: 턴마다 옆 칸으로 얼마나 번지는지 (0이면 안 번짐)
- 회복: 턴마다 기본값으로 얼마나 돌아가는지
- 반응 규칙: "조건 → 결과" 목록 (예: 온도 ≥ 100 그리고 물질=물 → 물질=증기, 압력 +2)
- 표시: 화면에 어떻게 보이는지 (색 덧칠, 입자, 아이콘)

변인끼리의 상호작용은 코드로 짝마다 짜지 않고 이 반응 규칙 표로 정의합니다. 그래서 변인 하나를 추가할 때 데이터와 규칙만 넣으면 되고, LLM은 이 카탈로그를 그대로 부품 목록으로 받습니다.

## 1. 칸의 값 (칸마다 숫자 또는 방향)

### 열과 기체
| 변인 | 설명 |
|---|---|
| 온도 | 열 피해, 물질 상태 변화, 체온에 영향 |
| 압력 | 압력차가 바람을 만들고 유닛을 밀어냄, 높으면 압착 피해 |
| 습도 | 높으면 불이 약해지고 전기가 잘 통함, 비/안개 생성 |
| 산소 농도 | 0이면 불 꺼짐, 질식 피해. 높으면 불이 폭발적으로 번짐 |
| 공기 밀도 | 낮으면(진공) 소리 안 퍼짐, 투사체 감속 없음 |

### 힘과 운동
| 변인 | 설명 |
|---|---|
| 중력 (방향+세기) | 유닛과 물질, 투사체를 끌어당김. 세면 이동 비용 증가, 공중 유닛 추락 |
| 바람 (방향+세기) | 가스, 연기, 불, 가벼운 유닛을 이동 |
| 마찰 | 낮으면(빙판, 기름) 밀린 유닛이 멈추지 않고 미끄러짐 |
| 탄성 | 높으면 벽에 부딪힌 유닛과 투사체가 튕겨 나옴 |
| 진동 | 지진. 쌓인 물질 무너짐, 유리/결정 파괴, 기절 확률 |

### 전기와 자기
| 변인 | 설명 |
|---|---|
| 전하 | 쌓이면 방전, 전도율 따라 이웃 칸으로 흐름 |
| 전도율 | 물/금속 칸은 높음. 전기 퍼짐 경로를 결정 |
| 자기장 (방향+세기) | 금속 유닛과 물질을 끌거나 밀어냄, 금속 투사체 휨 |
| 방사능 | 매 턴 피해, 일정 확률로 유닛 값 하나 무작위 변이 |

### 빛과 소리
| 변인 | 설명 |
|---|---|
| 밝기 | 어두우면 은폐(적이 못 봄), 너무 밝으면 눈부심(명중 감소) |
| 반사율 | 거울/얼음 칸에서 레이저, 빛이 반사 |
| 굴절률 | 레이저, 시야 경로가 휨 |
| 소음 | 큰 소리는 적을 끌어들이거나 깨움, 결정/유리 공명 파괴 |

### 화학과 생명
| 변인 | 설명 |
|---|---|
| 독성 | 매 턴 중독 부여, 바람 타고 이동 |
| 산성도 (pH) | 강산/강알칼리는 금속 부식, 방어 감소. 섞이면 중화 |
| 비옥도 | 높으면 식물이 자라 벽/덩굴이 됨, 생명 회복 |
| 부패 | 물질과 시체가 썩어 독/가스 생성 |

### 시공간
| 변인 | 설명 |
|---|---|
| 시간 속도 | 칸 안의 모든 변화와 행동 시간 배율. 0이면 정지(투사체도 멈춤) |
| 시간 흔적 | 칸이 과거 몇 턴 상태를 기억. 되감기 카드가 이걸 사용 |
| 공간 곡률 | 칸 사이 거리가 늘거나 줄어듦. 레이저가 휘고 이동 비용이 바뀜 |
| 공간 연결 | 두 칸을 포털처럼 이어붙임 (들어간 것이 반대편에서 나옴) |
| 현실 안정도 | 낮으면 칸의 값들이 매 턴 무작위로 흔들림, 0이면 균열(공허) |

### 마력과 추상
| 변인 | 설명 |
|---|---|
| 마력 밀도 | 이 칸에서 쓰는 카드 위력 배율 |
| 엔트로피 | 높으면 무작위 결과 확률 증가, 낮으면 모든 게 예측대로(확정) |
| 운 | 확률 판정 보정 (치명타, 회피, 변이) |
| 감정 기운 (공포/분노/평온) | 유닛의 행동 성향을 바꿈. 공포 칸에서는 적이 도망 |

## 2. 칸의 물질 (환경값에 반응해 상태가 바뀜)
- 물 ⇄ 얼음 ⇄ 증기 (온도), 물은 전도, 얼음은 반사/미끄러움
- 기름 (가연, 마찰 낮음), 가연성 가스, 독가스, 연기 (시야 차단)
- 불 (산소, 연료 필요), 플라즈마 (초고온, 전도)
- 흙 → 진흙 (습도), 모래 → 유리 (고온), 암석 → 용암 (초고온)
- 나무/덩굴 (가연, 비옥도로 자람), 씨앗
- 금속 (전도, 자성, 산에 부식), 결정 (빛 굴절, 소음에 파괴), 거울
- 산, 점액 (이동 방해), 수은 (전도, 독)
- 구름/비 (습도와 온도로 생성), 눈
- 진공 (공기 밀도 0), 공허/균열 (현실 안정도 0, 떨어지면 즉사급)
- 특이점 (중력원 자체, 주변을 계속 빨아들임)
- 벽 (단단함 수치가 있어 압력/진동/산으로 파괴 가능)

## 3. 유닛의 값
### 고유값
체력, 방어, 질량, 크기, 체온, 전하, 자성 여부, 부력(물에서 뜨는지), 개인 시간 속도, 시야 범위, 행동 성향(AI용), 운

### 저항 (각각 따로)
열, 냉기, 전기, 독, 산, 압력, 방사능, 시공간(되감기/정지 저항), 정신(공포/혼란 저항)

### 상태 (턴이 지나면 줄어듦)
젖음, 불붙음, 얼어붙음, 감전, 중독, 부식, 자화, 공중부양, 기절, 혼란, 공포, 투명, 시간 정지, 가속/감속, 거대화/축소, 위상 이동(벽 통과), 표식, 연결(다른 유닛과 피해 공유), 메아리(다음 행동 한 번 더), 복제체

## 4. 전장 전체 값
날씨(맑음/비/폭풍/눈), 낮과 밤, 기본 중력, 기본 시간 흐름, 전장 엔트로피, 현실 안정도 기본값

## 5. 상호작용 예시 (반응 규칙 표에서 나오는 결과)
- 온도↑ + 물 → 증기 → 압력↑ → 바람 → 가벼운 유닛 날아감
- 기름 + 산소 높음 + 불 → 폭발(압력 급상승) → 벽 파괴
- 젖음 + 전하 → 감전이 물 칸을 따라 퍼짐
- 금속 갑옷 적 + 자기장 → 벽에 끌려가 부딪힘 (질량×속도 = 충돌 피해)
- 마찰 0 + 중력 오른쪽 → 적이 미끄러져 공허로 떨어짐
- 시간 속도 0 칸에 레이저 → 레이저가 멈춰 있다가 시간 풀리면 발사
- 공간 연결 + 적 예고 공격 칸 → 적 공격이 적 자신의 칸으로 돌아감
- 거울 + 굴절 결정 → 레이저가 여러 갈래로 갈라짐
- 소음 + 결정 벽 → 공명으로 벽 붕괴
- 방사능 → 내 덱 카드의 수치가 무작위로 변이하는 위험한 보상
- 엔트로피 0 → 모든 확률 판정이 확정, 운 카드 무력화
- 공포 기운 + 좁은 통로 → 도망치던 적이 서로 밀쳐 막힘

## 6. 개수와 확장
- 칸의 값 약 30종, 물질 약 30종, 유닛 고유값/저항 약 20종, 상태 약 20종, 전장 값 6종
- 이 위에서 LLM은 "어느 칸에(모양), 무엇을, 얼마나, 몇 턴" 부품을 조합하므로 조합 수는 사실상 무제한
- 유저 카드에서 자주 요구되는데 없는 변인이 보이면 로그를 모아 새 변인으로 승격(운영자 승인)

## 7. 제4의 벽 변인 (메타 층)
게임 밖의 층을 건드리는 변인. 카드 부품으로 똑같이 쓰이며 위력 예산 안에서 움직인다.

### 화면과 UI
| 변인 | 설명 |
|---|---|
| 화면 방향 | 화면 뒤집기/회전. 입력 방향도 같이 바뀌는지는 별도 값 |
| 정보 가림 | 체력바, 카드 설명문, 적 예고, 타임라인 숫자를 가리거나 흐리게 |
| 거짓 표시 | 표시되는 수치가 실제와 다름 (예: 체력이 실제보다 적게 보임) |
| 손패 방향 | 흐르는 손패가 거꾸로 흐름 |
| 카메라 | 줌, 흔들림, 색 반전, 흑백 |
| 커서 | 마우스 커서 위치가 하나의 칸/유닛처럼 취급됨 (커서를 쫓는 적, 커서에서 나가는 레이저) |
| 가짜 시스템 메시지 | 게임 화면 안에서 오류창, 종료 화면, 크레딧을 흉내 (게임 화면임이 드러나게) |

### 규칙 자체
| 변인 | 설명 |
|---|---|
| 승리 조건 | 이번 전투의 승리/패배 조건 바꾸기 (예: N턴 버티기, 적을 죽이면 안 됨) |
| 턴 순서 | 적 턴과 내 턴 순서, 턴 횟수 바꾸기 |
| 비용 규칙 | 시간 비용을 체력으로 내기, 비용 0과 최대 맞바꾸기 |
| 카드 정직성 | 카드 설명이 실제 효과와 다르게 표시됨 (드러나는 시점까지) |
| 진영 | 나와 적, 아군과 적군의 소속 바꾸기 (몸 바꾸기의 기반) |

### 런과 저장
| 변인 | 설명 |
|---|---|
| 런 시드 | 남은 맵 다시 생성, 다음 방 종류 재배치 |
| 되감기 | 이전 방 진입 시점이나 전투 시작 시점 스냅샷으로 되돌리기 |
| 기록 | 이번 판 결과 화면에 남는 문구/기록 조작 |

### 다른 플레이어와 서버
| 변인 | 설명 |
|---|---|
| 남의 덱 | 최근에 죽은 다른 플레이어의 덱에서 카드 한 장 빌리기 |
| 유령 | 다른 플레이어의 사망 위치/캐릭터가 이번 전투에 적이나 아군으로 등장 |
| 유행 | 오늘 서버에서 가장 많이 쓰인 카드/변인에 보정 |
| 제작자 | 카드 제작자의 이름이나 그 카드의 좋아요 수가 효과에 반영 |
| 무작위 풀 | 전체 유저 카드 풀에서 무작위 카드 소환 |

### 현실
| 변인 | 설명 |
|---|---|
| 현실 시각 | 실제 시각/요일 (밤이면 어두움, 월요일이면 무기력) |
| 플레이 시간 | 이번 판 실제 플레이 시간, 연속 플레이 시간 |
| 창 상태 | 창 크기, 창이 포커스를 잃었을 때 (적이 몰래 움직임) |
| 입력 습관 | 카드를 고르는 데 걸린 실제 시간 (망설이면 손해) |
