# 카드 스튜디오 (카드 그리는 툴)

에디터에서 `scenes/card_studio.tscn`을 열고 F6(현재 씬 실행)을 누르면 됩니다. 전투 씬은 건드리지 않았습니다.

- 그림은 카드 그림칸 크기 그대로 64x51 픽셀. 오른쪽에 실제 카드 틀(3배)과 손패 크기(1배) 미리보기.
- 이름은 카드 이름칸에 바로 입력. 이름칸 폭을 넘는 글자는 막힘(칸이 흔들림).
- 설명문과 코스트는 서버의 LLM이 정하므로 미리보기에서는 흐릿한 줄과 `?`로 표시.
- 도구: 연필 B, 지우개 E, 채우기 G, 직선 L, 네모 R(Shift = 채운 네모), 스포이트 I(Alt+클릭도 가능), 좌우 대칭 M, 붓 크기 1~3, 방향키로 그림 한 칸씩 옮기기, Ctrl+Z / Ctrl+Y, 오른쪽 클릭은 항상 지우기.
- 러프 불러오기: 이미지 파일을 창에 끌어다 놓거나 Ctrl+V로 붙여넣으면 그림칸에 맞춰 줄이고 팔레트 색으로 바꿈.
- 작업 중인 그림과 이름은 자동 저장(`user://card_studio/`), 다시 열면 이어서 그림.

## 서버 연결 자리

`src/studio/card_submission.gd`가 서버와의 경계입니다. 보내는 것은 이름과 그림뿐이고(`payload()`), 서버가 아직 없어서
`endpoint`가 비어 있으면 `user://card_submissions/<id>/`에 `picture.png`와 `card.json`으로 저장합니다.
업로드 API가 정해지면 `endpoint`를 채우고 `_post()`에 HTTP 요청만 넣으면 되고, 스튜디오 화면은 바뀌지 않습니다.

스크린샷: `evidence/studio/` (`tools/capture_studio.gd`로 다시 찍을 수 있음).
