# 시간축 전투 설계 (1단계 전투 구조 개정)

작성일 2026-11-25. 기존 설계 문서 2.4 턴 구조와 2.5 손패를 대체합니다. **[결정]** 은 Luchenia가 정한 것, **[제안]** 은 Claude의 제안입니다.

## 1. 왜 바꾸나
- Luchenia 아이디어: 쓴 시간만큼 게임 세계가 실제로 흘러야 하고(3초 카드 = 3초 모션), 강한 카드는 탈진 시간 동안 캐릭터가 멈추고 적은 계속 움직여야 한다. **[결정]**
- 내 턴/적 턴을 나누면 이 아이디어와 어긋나므로 적 턴을 없애고 하나의 시간축으로 합친다. **[결정: 시간축 전투]**

## 2. 10초 라운드 타임라인 [결정: 방향 / 제안: 세부]
- 한 라운드 = 게임 시간 10초. 라운드 안에서 나는 행동을 고르고, 행동마다 걸리는 초만큼 세계가 흐른다.
- 세계는 1초 단위로 진행: 1초마다 환경 단계 1회(반응, 힘, 퍼짐), 상태/지속 효과는 라운드마다가 아니라 초마다 감소(데이터의 turns는 초 단위로 다시 맞춤).
- 행동이 걸리는 실제 초 = 카드 시간 × (1 / 내 칸 시간 속도). 느린 칸에서는 오래 걸리고 빠른 칸에서는 빨리 끝난다.
- 라운드 남은 시간보다 긴 행동도 쓸 수 있고, 넘친 초는 다음 라운드에서 깎인다(빚). **[제안]**
- 라운드 끝 표시는 리듬용이며, 라운드 사이에 별도 적 턴은 없다.

## 3. 적
- 적은 같은 시간축 위에서 행동한다. 각 적은 "다음 행동 시각"을 가지고, 그 시각에 카드를 쓰거나 예고를 건다.
- 예고는 "N초 뒤 이 칸들" 형태로 칸 위와 상단 타임라인에 함께 표시. **[제안]**
- 한 칸 공격은 한 칸 이동으로 다 피해지므로, 적 공격은 아래 패턴을 섞는다. **[결정: 범위 공격 필요 / 제안: 패턴]**
  1. 범위: 3×3, 십자, 직선 관통, 부채꼴. 피하려면 2칸 이상 움직이거나 특정 방향으로만 피해야 함
  2. 안전지대형: 전장 대부분을 치고 몇 칸만 비움("이 칸들만 안전")
  3. 추적형: 예고는 짧고(1~2초) 범위는 작지만 발동 시점의 내 위치를 향함
  4. 장판형: 맞은 칸에 불/독/전하가 남아 몇 초 동안 그 칸을 위험하게 만듦
  5. 연계형: 두 예고가 겹쳐서 안전한 칸이 하나뿐
  6. 환경 조작형: 중력/바람/마찰을 바꿔 나를 예고 칸 쪽으로 밀거나 미끄러뜨림
  7. 구속형: 내 칸 시간 속도를 낮춰 이동 자체를 비싸게 만듦
- 이동에도 시간이 든다(아래)는 점이 핵심: 피하면 그만큼 공격할 시간을 잃는다.

## 4. 이동 [제안, 기존 결정 개정]
- 기존: 턴당 무료 1칸. 시간축에서는 "1칸 이동 = 1초"로, 시간이 있는 한 여러 칸 이동 가능.
- 무료 1칸을 남기면 1칸 공격 회피가 공짜가 되므로 1초 비용을 제안. 캐릭터 기본 능력(이동 대신 다른 능력)은 그대로 "1초짜리 기본 행동"으로 바뀐다.

## 5. 손패와 휠 드로우 [결정]
- 손패 5장, 아무 카드나 골라서 사용.
- 마우스 휠로 좌/우로 굴리면 굴린 쪽 끝 카드가 버려지고 반대쪽 끝에 새 카드가 들어온다. 1초 소모.
- 끝 카드가 무거우면 넘기는 데 더 오래 걸린다(무게 = 초). **[제안: 무게 2 = 2초]**
- 연출은 원형/부채꼴 손패로 해서 일직선 벨트처럼 보이지 않게. **[제안]**

## 6. 카드 시간과 탈진 [결정]
- 카드 시간 = 그 카드 모션이 걸리는 게임 시간. 3초 카드는 3초짜리 모션, 그 동안 세계가 흐른다.
- 강한 카드는 "탈진 N초"를 가질 수 있다. 탈진 동안 캐릭터는 행동 불가, 세계와 적은 계속 진행.
- 위력 계산: 시간과 탈진 모두 할인 요소(탈진 1초 = 시간 1초보다 크게 할인). **[제안]**

## 7. 고난도 [결정]
- 수명 손패는 고난도 모드나 고난도 캐릭터용으로 남긴다.

## 8. 구현 범위 (다음 PR) [제안]
- Battle을 시간축으로 재작성: `advance(seconds)`가 1초씩 환경 단계와 적 행동 시각을 처리.
- 적 행동 스케줄, 초 단위 예고, 범위 패턴 적 카드 3~5종 추가, 이동 1초, 휠 드로우, 탈진, 화면 상단 타임라인 막대.
- 시뮬레이션 코어(격자, 반응, 부품 실행기, 위력 계산기)는 재사용.

## 9. 이어지는 시계 확정과 멀티플레이 방향 (2026-11-25 추가)
- **[결정]** 라운드 10초 한도는 두지 않는다. 시간은 플레이어가 행동(카드, 이동, 휠, 기다리기)을 고를 때만 그 초만큼 흐르고, 고르는 동안은 멈춰 있다. 0초 카드는 시간을 쓰지 않는다. 라운드는 손패 보충 박자로만 남는다.
- **[결정: 방향]** 멀티플레이: 모든 플레이어가 시간이 드는 행동을 하나씩 정해야 게임 시간이 흐른다. 아직 정하지 않은 사람이 있으면 모두 기다린다.
- **[제안: 세부]**
  1. 행동 길이가 다를 때: 모두 정하면 시계는 "가장 먼저 행동이 끝나는 사람"까지만 흐른다. 그 사람만 다시 고르고, 긴 행동을 고른 사람은 행동이 끝날 때까지 기다린다. 예: A 3초, B 1초 → 1초 흐름, B가 다시 고름 → B가 1초를 또 고르면 2초까지, … A가 끝나는 3초에 A와 B가 같이 고른다.
  2. 같은 초에 여러 플레이어 행동이 끝나면 정해진 순서(플레이어 번호)로 적용하고, 모두 적보다 먼저 적용한다(1인용의 "같은 초면 플레이어 먼저"와 같음).
  3. 0초 카드는 고르는 즉시 적용되고 다른 플레이어에게도 바로 보인다.
  4. 긴 행동을 고른 사람이 지루하지 않게, 동료가 고른 행동과 끝나는 시각을 타임라인 막대에 함께 표시한다.
  5. 온라인에서는 한 사람이 너무 오래 안 고를 때를 위한 제한 시간(예: 60초 뒤 자동 "1초 기다리기")이 필요하다.
  6. 기술 바탕: 전투는 시드와 명령 목록만 같으면 결과가 같다(테스트로 보장). 멀티플레이는 명령만 주고받는다. 구현할 때 플레이어마다 "다시 움직일 수 있는 시각"을 갖게 바꾼다(적은 이미 이 방식).
- 라운드 10초 한도 + 딱 맞추기 쾌감은 고난도 모드 후보로 남긴다.
